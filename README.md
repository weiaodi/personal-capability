## 学习路径

### 阶段 0｜入门（第 1—2 周）

建立两个习惯：学完一个概念就闭卷复述一次；每周至少用一次学到的东西处理真实事情。

- 投资：读计划第二章（个人财务），做一张自己的资产负债和现金流表。
- 理解人：读计划第 1 周，做「事实—解释」分离练习。

### 阶段 1｜打基础（第 1—3 个月）

- 投资：资产与交易机制、三张财报。目标：能解释一笔交易如何成交、一家公司如何赚钱。
- 理解人：情绪、评价、调节；动机与推理。目标：能在一次真实分歧中先核实再判断。
- 并行主题：决策与概率思维（两个计划都依赖它）。用 AI 出概率题、拆解你最近做过的一个决定，检查自己事后改口了哪些判断。

### 阶段 2｜深入分析（第 4—6 个月）

- 投资：盈利质量、商业模式、估值（相对估值和 DCF）。目标：完成一份公司研究备忘录。
- 理解人：身份、信任、关系、群体与权力。目标：完成一次有记录的困难对话复盘。
- 并行主题：表达与写作。每份投资备忘录、对话复盘本身就是写作练习；让 AI 当审稿人，指出结构问题和证据缺口。

### 阶段 3｜综合应用（第 7—12 个月）

- 投资：宏观与市场预期、组合管理、复盘。目标：写出自己的投资政策，用模拟或小仓位验证。
- 理解人：制度与博弈、谈判、毕业项目。目标：选一个真实可控的问题，完成从访谈到报告的完整闭环。
- 并行主题：产品与商业理解。用理解人计划第 46 周（用户与商业迁移）作为入口，选一个你熟悉的产品分析其用户价值和商业模式。
- 全程：精力管理不单独立项，但睡眠和运动是学习可持续的前提；中断两周以上先恢复状态再补进度。

## AI 辅助方式

每个主题进入时，直接把对应计划章节发给 AI，让它：

1. 解释核心概念，给出适用条件和反例。
2. 出题考你，包括一道你大概率答错的题。
3. 陪你分析一个你最近的真实案例（投资决策、一次分歧、一个产品）。
4. 审你的输出（备忘录、复盘、分析），指出证据不足和逻辑漏洞。

底线：AI 给的事实、数字、规则必须回到计划里标注的原始来源核验；AI 负责加速理解和提供反方观点，最终判断自己下。

## 执行约定

- 每周一个最小交付物：一张概念解释、一次真实应用或一份分析，任选其一。
- 两个计划并行时各自放慢，允许 52 周计划用 18 个月走完。
- 中断后从最近的真实问题恢复，不补旧账。
