# Personal Capability

个人能力提升项目，定位为长期内容摄入与能力训练仓库。目标不是收集资料，而是形成「输入 → 理解 → 实践 → 记录 → 复盘」的稳定闭环。

## 学习主线

当前仓库包含三条主线：

| 主线 | 核心目标 | 主要文件 |
|---|---|---|
| 投资理财 | 建立个人财务、交易机制、公司分析、估值和组合管理的基础体系 | [investing_learning_plan_24_weeks.md](investing_learning_plan_24_weeks.md) |
| 理解人 | 提升情绪理解、动机分析、沟通、边界、关系与制度分析能力 | [psychology_human_behavior_52_week_plan.md](psychology_human_behavior_52_week_plan.md) |
| 学习系统 | 解决如何执行、记录、复习和持续改进的问题 | [learning_system.md](learning_system.md) |

另有一份主题相近的理解人计划：[understanding_people_52_week_learning_plan.md](understanding_people_52_week_learning_plan.md)。它包含更完整的目录锚点和来源索引，可与当前主线互为补充。后续如需整理重复内容，应先确认保留标准，再合并或归档。

## 能力缺口补充路线

针对当前仓库缺少的学习科学、决策判断、职业发展、产品商业、健康精力和 AI 工具使用，见 [capability_roadmap.md](capability_roadmap.md)。

该路线分为六个阶段：

1. 学习科学与执行习惯
2. 决策与概率思维
3. 表达、写作与职业发展
4. 产品思维与商业理解
5. 健康与精力管理
6. AI 辅助学习与工具化

## 日常使用方式

1. 每周先打开 [learning_system.md](learning_system.md) 的「周启动」和「周复盘」模板。
2. 从对应学习计划中选取本周主题，不贪多。
3. 学习产出写入 `notes/`，进度写入 `progress.md`。
4. 每月复盘一次目标、证据、实践记录和下一阶段调整。

建议目录结构：

```text
personal-capability/
  README.md                         # 总览与入口
  learning_system.md                # 学习执行系统
  capability_roadmap.md             # 能力缺口路线
  progress.md                       # 阶段与周进度记录
  notes/                            # 学习笔记与知识卡片
    inbox/                          # 未整理输入
    concepts/                       # 概念卡
    cases/                          # 案例复盘
    reviews/                        # 周/月复盘
  plans/                            # 后续新增专项计划
```

## 执行原则

- 每周固定一个最小交付物，不用阅读量衡量进度。
- 输入必须转化为概念卡、案例复盘、练习记录或行动计划之一。
- 重要结论必须区分来源证据与个人推断。
- 不把学习系统本身当作主要产出，避免用整理资料替代真实练习。
- 中断后从最近一个真实问题重新开始，不要求从第一章补完。
